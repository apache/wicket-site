Reference guide

The reference guide, called the User Guide on this site before, is the complete guide to Wicket in one document per release line. The Documentation links it for every line, as one page or PDF, with the Javadoc next to it: Wicket 10, Wicket 9, Wicket 8, Wicket 7.

Books, courses and talks

  • Books about Wicket, from Wicket in Action to the Apache Wicket Cookbook.
  • Apache Wicket Kompakt, a German course with many practical examples.
  • Starting with Apache Wicket, for Wicket 9 and later, with forms, components, MongoDB and Spring Boot.
  • An introduction to Wicket, slides for developers new to Wicket.
  • A quick tour of Wicket, small examples of what Wicket code looks like, and the live examples running on a server.

The Wicket wiki holds older articles, the migration guides and community pages.

Libraries and integrations

The community builds and maintains libraries on top of Wicket. They have their own release cycles and maintainers.

  • WicketStuff gathers community-provided projects, from integrations with JavaScript libraries to REST resources and asynchronous tasks; the project overview lists them.
  • Wicket Spring Boot configures Wicket and its extensions automatically in a Spring Boot application.
  • Wicket-Bootstrap integrates Bootstrap’s components and styles, with a showcase of every feature.
  • Wicket jQuery UI wraps the jQuery UI and Kendo UI widgets as Wicket components.
  • Modern web development with Apache Wicket shows Wicket with Spring Boot, Hazelcast and WebJars in working examples.

The Integration topic of the documentation covers Spring, CDI and the other integrations that ship with Wicket.
