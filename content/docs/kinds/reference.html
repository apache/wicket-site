Getting started

  • Wicket modules The artifacts Wicket is released as, what each one contains, which Wicket modules it depends on, and which you need for testing and tooling.
  • Maven dependencies The Maven dependencies, versions, scopes and build settings a Wicket project needs.
  • Application settings How a Wicket application is started and configured, the settings objects with their main options and defaults, and what development and deployment mode change.
  • Glossary Plain-English definitions of the Wicket terms used in this guide, each compared with what other web frameworks call it.

Components and markup

  • Wicket tags and attributes Every tag and attribute in the wicket namespace, what it does, which attributes it takes, with a minimal example of each.

Models

  • Model classes Every model class and model interface in wicket-core, the default methods of IModel, the factory methods and the component methods that work with models.

Forms

  • Form components Every form, input, choice, upload and submit component in wicket-core and wicket-extensions, with the markup tag it needs and the type of its model.
  • Validators and converters The built-in validators, form validators and converters, with their message keys, the variables in their messages and their default texts.

Lists and tables

  • Repeaters The repeaters of wicket-core and wicket-extensions compared, what each needs and when it re-creates items, plus data providers, navigators and table parts.

Ajax and JavaScript

  • Ajax components The Ajax components in wicket-core and wicket-extensions, what each does and which callback you override.
  • Ajax behaviors The Ajax behaviors and call listeners in wicket-core and wicket-extensions, the callback each one calls and its lambda factory method.

WebSockets

  • WebSocket JavaScript API The Wicket.WebSocket functions and the events your JavaScript can subscribe to on a page with a WebSocket behavior.

Links and URLs

  • Request mappers The request mappers that turn URLs into request handlers and back, the mount methods of WebApplication, and the syntax of mount paths.

Resources

  • Header items Every header item type with its factory methods, the tag it renders and where it ends up, the rendering order, Ajax behaviour and the header response decorators.

Requests and lifecycle

  • Component lifecycle The stages a component goes through and every hook method Wicket calls on it, in order, with who calls it and when.
  • Request processing The objects that serve a request, the steps of RequestCycle in order, the request cycle listener hooks, and the request handlers Wicket ships.

Localization

  • Where Wicket looks for texts The exact order in which Wicket searches resource bundles for a key, the file names it tries, and the settings that change the search.

Security

  • Security headers and external checks The response headers that scanners such as Mozilla Observatory check, which of them Wicket sends by default, and the Wicket API or hook that sets each one.

Testing

  • WicketTester The methods of WicketTester, grouped by purpose, with FormTester, TagTester and the JUnit helpers of the wicket-tester module.

Integration

  • WicketStuff The community modules of the WicketStuff project, what each one adds to Wicket, and how to add one to a Maven build.
