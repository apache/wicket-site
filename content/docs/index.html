Start here

Five lessons that build one application, from an empty project to a tested page with Ajax. To get a running project in a minute first, use the quick start.

  1. Build your first application Generate a project from the quickstart, run it, and build a home page with a label, a click counter and a link to a second page.
  2. Give every page the same layout Move the header, navigation and footer of your application into a base page and two panels, so every page shares one layout.
  3. Build a form that saves data Add a guestbook page with a form that validates its input, saves entries and lists them, and shows errors and a confirmation.
  4. Update a page with Ajax Make the click counter and the guestbook form update only the parts of the page that change, open the form without a reload, and refresh the guestbook every ten seconds.
  5. Test a page with WicketTester Write JUnit tests that render your pages, click links, submit the guestbook form and check Ajax updates, without a browser or a server.

Topics

Each topic gathers its lessons, how-to guides, reference and explanation on one page.

  • Getting started Create a project, configure the application and learn what Wicket is made of.
  • Components and markup Pages, panels, borders and fragments, and how Java components meet their HTML.
  • Models How components get and keep their data.
  • Forms Input fields, validation, conversion, uploads and submitting.
  • Lists and tables Repeat markup for each item in a list, page through data.
  • Ajax and JavaScript Update parts of a page without reloading it, and work with JavaScript.
  • WebSockets Push updates from the server to the browser.
  • Links and URLs Link between pages, pass parameters and shape the URLs.
  • Resources Serve CSS, JavaScript, images and generated files.
  • Pages and state Stateful and stateless pages, the page store and the session.
  • Requests and lifecycle How a request is processed and what happens to a component along the way.
  • Localization Translate texts, formats and choices.
  • Security Log users in, restrict access and harden the application.
  • Testing Test pages, forms and markup without a browser.
  • Integration Spring, CDI, EJB, OSGi and monitoring.

  • A–Z indexEvery Wicket class the documentation explains, and every page by title.
  • Wicket tags and attributesEvery tag and attribute in the wicket namespace, what it does, which attributes it takes, with a minimal example of each.

Upgrading

Every major release has a migration guide on the wiki with the API changes and what to do about them, linked from its release line page. The upgrade paths show the route from a line that is ending or has ended to one that is supported.
