API documentation

Maven downloads the sources with every Wicket release, so your IDE shows the Javadoc when you hover over a class. To link to it, use the Javadoc online: {% assign apidocs = '' | split: '' %}{% for line in site.data.releases.lines %}{% if line.status == 'lts' or line.status == 'current' %}{% capture a %}Wicket {{ line.series }}{% if line.status == 'lts' %} (LTS){% endif %}{% endcapture %}{% assign apidocs = apidocs | push: a %}{% endif %}{% endfor %}{{ apidocs | join: ' and ' }}. Older lines link to theirs from their release line page.

Upgrading

Every major release has a migration guide on the wiki with the API changes and what to do about them, linked from its release line page. The upgrade paths show the route from a line out of service to one that is supported.

Older versions

The documentation covers the release lines in service. Pages marked with a version, like Wicket 11+, need that version or later. Every line also has its reference guide as one document; for lines out of service it is their only guide: {% assign older = "9,8,7" | split: "," %}{% for v in older %}Wicket {{ v }}{% unless forloop.last %}, {% endunless %}{% endfor %}.
