Reference guide

The reference guide is the complete Wicket user guide of one release line, in a single document to read through or search. The Javadoc lists every class, method and setting; Maven downloads the sources with every release, so your IDE also shows it when you hover over a class.

Upgrading

Every major release has a migration guide on the wiki with the API changes and what to do about them, linked from its release line page. The upgrade paths show the route from a line that is ending or has ended to one that is supported.
