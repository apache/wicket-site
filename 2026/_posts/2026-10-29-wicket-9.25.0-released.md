The Apache Wicket PMC is proud to announce Apache Wicket 9.25.0!

Apache Wicket is an open source Java component oriented web application
framework that powers thousands of web applications and web sites for
governments, stores, universities, cities, banks, email providers, and
more. You can find more about Apache Wicket at https://wicket.apache.org

Final release of Wicket 9
-------------------------

> This is the final release of Wicket 9. With this release the 9.x
> branch has reached end of life: there will be no further 9.x releases,
> not even for security fixes. Wicket now releases a new major version
> every three months, with a long-term support release once a year. Read
> about our [new release cadence and support policy]({{ site.baseurl }}/news/2026/09/11/release-cadence.html)
> and see the [upgrade options]({{ site.baseurl }}/versions/wicket-9.x/#upgrade).

We use semantic versioning for the development of Wicket, and as such
no API breaks are present in this release compared to 9.0.0.

New and noteworthy
------------------

 * Vulnerable dependencies have been updated (WICKET-7199)
 * Fixed a regression from the Button XSS fix in 9.24.0 (and 10.11.0):
   `setEscapeModelStrings(false)` on a Button had no effect, so markup
   in a button label was escaped (GH-1576)
 * CSP headers are now also set when a `RenderPageRequestHandler` is
   wrapped in more than one `IRequestHandlerDelegate` (WICKET-7205)

Using this release
------------------

With Apache Maven update your dependency to (and don't forget to
update any other dependencies on Wicket projects to the same version):

{% highlight xml%}
<dependency>
    <groupId>org.apache.wicket</groupId>
    <artifactId>wicket-core</artifactId>
    <version>9.25.0</version>
</dependency>
{% endhighlight%}

Or download and build the distribution yourself, or use our
convenience binary package you can find here:

 * Download: https://wicket.apache.org/versions/wicket-9.x/#manually

<!--more-->

Upgrading from earlier versions
-------------------------------

If you upgrade from 9.y.z this release is a drop in replacement. If
you come from a version prior to 9.0.0, please read our Wicket 9
migration guide found at

 * http://s.apache.org/wicket9migrate

Now that Wicket 9 has reached end of life, plan your move to Wicket 10,
our long-term support release, supported until July 2027. For upgrade
options see:

 * https://wicket.apache.org/versions/wicket-9.x/#upgrade

Have fun!

— The Wicket team
